# Security Policy

## Reporting Security Issues

We take security seriously and encourage you to report any security vulnerability promptly so that appropriate action can be taken.

To report a security issue in this CLI, please use [GitHub security advisories for this repository](../../security/advisories/new) rather than a public issue.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us maintain the security of
our software. If you believe you have found a security vulnerability, please adhere to responsible
disclosure practices by allowing us a reasonable amount of time to investigate and address the issue
before making any information public.

## Reporting Non-CLI Related Security Issues

If you encounter security issues that are not directly related to this CLI but pertain to the services
or products provided by Cadenya, please follow Cadenya's security reporting guidelines.

### Cadenya Terms and Policies

Please contact support@cadenya.com for any questions or concerns regarding the security of our services.

---

Thank you for helping us keep this project and the systems it interacts with secure.
